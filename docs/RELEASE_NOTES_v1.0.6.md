# v1.0.6 — 추가 제보 5건 재검수 및 기체·인물명 표기 교정

v1.0.6은 GitHub에 새로 열린 초반 플레이 제보를 특정 화면 한 곳만 고치는 방식으로 처리하지 않고, 같은 일본어 키가 사용되는 시나리오 대사·실행 파일 문자열 풀·파일럿/로봇 백과·용어사전을 모두 추적해 수정한 패치입니다. 기존 v1.0.5의 전체 검수·압축·포인터 검증 구조는 유지하면서, #75~#79에서 보고된 표기와 대사 문제를 원문 레코드 단위로 반영했습니다.

이번 버전은 에뮬레이터를 실행하지 않았습니다. 사용자의 실행 허가 없이 구동하지 않는다는 원칙에 따라, 원본 재추출, 전체 정적 QA, ISO 재조립, xdelta 적용 왕복 검증, 압축 멤버·스크립트 점프·파일 크기 검증으로 배포 전 검사를 완료했습니다.

## 이슈별 수정 내역

### [#75 — 잭스 대사 수정](https://github.com/snake7594/shin-srw-korean-patch/issues/75)

시나리오 원문 레코드 `SCE-056-0014`를 직접 대조했습니다.

- 원문: `ゼクス「大佐は、お忙しい。\n お前達の相手は、私がしよう」`
- 이전 번역: `젝스「대령님은, 바쁘시다.\n 너희 상대는, 내가 하지」`
- 수정 번역: `젝스「대령님은 바쁘시니,\n 너희들은 내가 상대하지」`

쉼표가 일본어 문장 단위 그대로 남아 어색했던 부분과, `お前達の相手は`의 목적·대상 관계가 흐려졌던 부분을 함께 고쳤습니다. 레코드 ID를 유지하고 해당 대사의 본문만 교체했으므로 다음 화자의 레코드와 섞이지 않습니다.

### [#76 — 인터미션의 간이지 표기](https://github.com/snake7594/shin-srw-korean-patch/issues/76)

## 회귀 방지

`tools/qa_translation.py`의 회귀 목록을 이번 제보에 맞춰 갱신했습니다. 다음 잘못된 표현이 번역 payload에 다시 들어오면 QA가 실패합니다.

- `대령님은, 바쁘시다.`
- `너희 상대는, 내가 하지`
- `간이지`
- `핑거하트`
- `핑거핫트`
- `레우르라`
- `조로앗`

정정된 `건이지`, `마베트 핑거햇`, `레우루라`, `조로아트`는 실행 파일 문자열 풀·시나리오·사전·용어사전에서 교차 확인했습니다.
