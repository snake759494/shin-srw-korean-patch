# v1.0.4 — 시나리오 대사 오타 수정

GitHub 이슈 #9의 제보를 반영한 후속 릴리스입니다. v1.0.3의 강화 화면 수정과
크로노클 대사 수정은 그대로 유지하고, 시나리오 대사 한 곳의 오타만 추가로 교정했습니다.

## 수정 내용

- 시나리오 `SCE-007-0073`의 가리 대사에서 `무, 뭡니까!?`를 `뭐, 뭡니까!?`로
  수정했습니다.
- 해당 레코드 외의 대사·화자·스크립트 점프·파일 배치는 변경하지 않았습니다.

## 정적 검증

- 원본 Track 1/2 크기·SHA-256 및 추출 매니페스트 일치
- SCEDATA 128개 멤버 재압축·런타임 버퍼 검증
- BTTMES 점프 8,750곳 검사, 메시지 중간 착지 0건
- 출력 Track 1 크기 650,607,888바이트(원본 대비 468,048바이트 증가)
- 출력 Track 1 SHA-256 `4e1f1bba392579d79a2e9d17b59d5b2b2ee1e382eff720601a33730c8216d9bd`
- xdelta를 원본에 역적용해 결과 이미지 SHA-256과 일치하는지 확인
