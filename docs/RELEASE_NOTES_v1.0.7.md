# v1.0.7 — 무기 목록 마커 보존 및 초반 시나리오 후속 제보 반영

v1.0.7은 v1.0.6 이후 열린 #80~#86을 원문 레코드·실행 파일 문자열 풀·폰트 타일·백과사전 데이터까지 역추적해 수정한 후속 패치입니다. v1.0.6에서 반영한 #75~#79의 교정도 그대로 포함하며, 초반 화면에서만 보이는 현상을 한 문자열만 바꾸는 방식으로 처리하지 않고 전체 빌드 입력과 포인터 구조를 다시 검증했습니다.

## 이번 릴리스에서 해결한 제보

### #80·#81 — 보로트/V2 건담 무기명 뒤에 붙는 불필요한 「아」

- 무기 문자열 자체의 종료 바이트 `FF`나 무기명 길이가 원인이 아니었습니다.
- 원본 폰트의 `F4 70` 슬롯(글리프 `肉`)은 무기 목록 상태 표시 루틴이 문자열 뒤에 출력하는 인라인 UI 마커였습니다.
- 일반 대사와 문자열 풀의 사용 빈도만 세면 이 슬롯이 사용되지 않는 것으로 보여 한글 글리프 할당기가 첫 한글 「아」를 `F4 70`에 배치하고 있었습니다.
- `F4 70`을 인라인 UI 예약 슬롯으로 명시해 원본 타일을 바이트 단위로 보존했습니다. 「아」는 다음 사용 가능한 슬롯으로 재할당했습니다.
- 빌드 QA가 retail EXE와 결과 EXE의 폰트 오프셋 `0x73438 + 0x470 × 32`를 직접 비교해 이 회귀가 다시 생기지 않도록 했습니다.

### #82 — 전투 대사 오탈자

다음 두 BTTMES 레코드의 `무.. 마,`를 원문의 의미에 맞는 `뭐.. 마,`로 수정했습니다.

- `BTT-39-14-0171EB`
- `BTT-E1-14-0471EB`

### #83·#84 — 코우지 대사의 말투와 줄바꿈

초반 마징가Z·보로트 교환 장면을 원문과 대조해 코우지가 갑자기 존댓말로 바뀌지 않도록 반말 어미를 통일했습니다.

- `SCE-058-0038`: `어떻게 된 거예요. 이건` → `어떻게 된 거야, 이건`
- `SCE-058-0040`: `타기 전에 말해요.` → `타기 전에 말해 줘.`
- `SCE-058-0105`: `한 번만, 마징가Z랑 보로트` 뒤에서 문장이 끊기던 줄을 `마징가Z랑` 뒤에서 끊고 `보로트를`로 이어지게 수정
- `SCE-058-0033`, `0103`, `0109`, `0111`, `0113`, `0125`, `0129`도 같은 장면의 말투를 함께 재검수

### #78 — 지시문·구호반 표기

- `SCE-057-0032`: `조사해 다오` → `조사해라`
- `SCE-057-0037`, `SCE-057-0038`: `구호반` → `구조반`
- `SCE-057-0038`: `진로 밖으로 이동시켜 줘` → `진로 밖으로 이동시켜라`

### #77·#79 — 인물명·기체명

실행 파일 이름 풀, 시나리오 대사, 파일럿/로봇 백과, 용어사전의 동일 항목을 함께 갱신했습니다.

- `유카 마이라스` → `유카 마일라스`
- `미리에라 카탄` / `미리에라` → `밀리에라 카탄` / `밀리에라`
- `게드라프` → `게들라프`
- `리그샤코` → `릭샤코`
- 기존 제보의 `조로앗` → `조로아트`, `마베트 핑거햇` 등 v1.0.6 교정도 포함

### #85 — 적 파일럿명

`ゴズ=バ-ル`의 모든 번역 출현을 `고즈 바르`에서 `고즈 발`로 통일했습니다. 시나리오 반복 대사, 파일럿 이름 풀, 용어사전, 참조 데이터까지 대조했습니다.

### #86 — 맵상 명칭

시스템 문자열 풀의 맵 전용 항목 `エンジェルハイロゥ`를 `엔젤하이로우`에서 `엔젤하이로`로 수정했습니다. 같은 일본어 키를 사용하지 않는 시나리오 제목·설명 항목은 임의로 바꾸지 않고 원래 문맥을 유지했습니다.
