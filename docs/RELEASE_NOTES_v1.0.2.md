# v1.0.2 — BTTMES 원본 위치 유지 및 프로로그 검증

## 이번 릴리스

v1.0.1에서 CUE의 Track 2 프리갭을 고쳤는데도 SwanStation에서 1화 볼테스 V
필살기 후 정지한다는 [이슈 #1](https://github.com/snake7594/shin-srw-korean-patch/issues/1)이
보고되었습니다. 또한 [이슈 #5](https://github.com/snake7594/shin-srw-korean-patch/issues/5)의
프로로그 대사 화면 31장을 원본 SCEDATA 레코드와 다시 대조했습니다.

## 이슈 #1 분석과 수정

정지 지점의 전투 대사는 `BTT-A8-0F-03B428` (`「天空剣!! Vの字切りぃぃぃっ!!!」`)입니다.
대사 레코드 자체는 정상이고, BTTMES 내부 점프도 메시지 중간을 가리키지 않았습니다.
문제는 v1.0.1에서 확장된 BTTMES를 데이터 트랙 끝으로 옮긴 레이아웃이었습니다.
게임의 CD 로더가 사용하는 정품 배치와 달라졌고, CUE 프리갭을 바로잡아도 해당 코어에서
정지할 수 있었습니다.

v1.0.2는 다음 방식으로 레이아웃을 고정했습니다.

- BTTMES의 정품 LBA `26790`을 그대로 유지합니다.
- BTTMES를 169섹터에서 183섹터로 확장하고, 바로 뒤의 UNTDATA부터 끝까지를 14섹터
  뒤로 이동합니다.
- ISO9660 루트·BTT·MAP·MWA·VCE·MOV 디렉터리의 파일 및 디렉터리 extent를 함께
  갱신하고, PVD와 `NULL.DA`의 Track 2 경계도 갱신합니다.
- 이동한 249,461개 Mode2 섹터를 원본과 비교하고, 번역으로 바뀐 타이틀 그래픽 섹터는
  예상 사용자 데이터와 EDC/ECC를 검증합니다.
- CUE의 Track 2 `INDEX 00 00:00:00` / `INDEX 01 00:02:00` 표기는 유지합니다.

## 이슈 #5 분석과 수정

첨부된 프로로그 화면은 SCEDATA 시나리오 1의 `SCE-001-0004`부터
`SCE-001-0092`까지 89개 레코드에 해당합니다. 이 범위의 대사를
`data/screenshot_translation_ko.json`으로 관리하고, 전체 SCEDATA 재빌드에서
고정 레코드 경계 안에 다시 적용했습니다. 따라서 프로로그 대사가 다른 레코드와
합쳐지거나 다음 화자의 이름을 침범하지 않습니다.

`0f089d6f6837cb7cfd010f6de53860cb7313581a21df1e502ab58df03c24dc28`입니다.

이번 작업에서는 사용자의 요청에 따라 에뮬레이터를 실행하지 않았습니다. 따라서 이슈
#1은 정적 패치와 릴리스 검증 결과를 댓글로 남기되, SwanStation에서 실제로 정지 지점을
통과했다는 사용자 확인 전까지 열어 둡니다. 프로로그 대사 이슈 #5는 해당 범위가
릴리스에 포함되어 닫습니다.
