# v1.0.1 — SwanStation CUE 경계 수정

v1.0.0의 번역 데이터와 Track 1 패치는 그대로 유지하면서, SwanStation에서 1화 전투
연출 뒤 다음 화면으로 넘어가지 않을 수 있는 멀티트랙 CUE 표기를 수정했습니다.

## 수정 내용

정품 Track 2 BIN 앞에는 150섹터(2초) 프리갭이 이미 포함되어 있습니다. 기존 간편 적용기는
이를 생략하고 Track 2를 `INDEX 01 00:00:00`으로 선언했습니다. v1.0.1에서는 다음처럼
프리갭과 실제 INDEX 01을 명시합니다.

```text
TRACK 02 AUDIO
  INDEX 00 00:00:00
  INDEX 01 00:02:00
```

이 표기는 번역으로 확장된 데이터 트랙 끝과 ISO의 `NULL.DA` 시작 LBA(데이터 트랙 끝+150)를
SwanStation의 오디오 트랙 경계에 맞춥니다. `PREGAP`은 실제 BIN에 프리갭이 있으므로 추가하지
않았습니다.

또한 저장소 빌드에서 명시한 상대경로가 `work/` 하위 프로세스에서도 유지되도록 보완했고,
Windows cp949 콘솔에서 일본어가 포함된 빌드 보고서 출력이 성공한 빌드를 실패로 바꾸던 문제를
수정했습니다.

## 주의

이 릴리스의 CUE/ISO 구조는 정적 검증을 완료했습니다. SwanStation 실기 확인은 사용자의
에뮬레이터 실행 허가 후 진행할 수 있습니다.
