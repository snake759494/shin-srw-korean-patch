# v1.0.5 — 전체 시나리오 검수 및 상태창 잔존 한자 수정

초반 제보만 부분적으로 고치는 대신, 추출된 전체 시나리오·전투 대사를 원문 레코드와 다시 대조했습니다. 이름·용어·띄어쓰기·줄바꿈 변형을 함께 점검하고, 같은 문제가 후반 시나리오에서 반복되지 않도록 정적 회귀 검사를 빌드 과정에 추가했습니다.

## 주요 변경

- GitHub 이슈 #10~#73의 제보를 원문과 대조해 오타, 조사, 띄어쓰기, 인물명, 부대명, 용어를 일괄 교정했습니다.
- `チェ-ン`은 인물명 `첸`으로만 교정하고, 무기명 `체인`과 지명·단어 내부의 `체인`은 보존했습니다.
- 상태창이 문자열 풀을 거치지 않고 직접 읽던 실행 파일 오프셋 `0x70300`의 `無/有`를 `없/있`으로 교정했습니다. 두 글자와 패딩 8바이트 구조를 유지합니다.
- 고정 상태 라벨 `近攻撃`을 `근거리`로 정리해 `원거리`와 용어를 맞췄습니다.
- 파일럿 사전·로봇 사전·시나리오 제목의 동일 인물명과 기체명을 함께 정리했습니다.

## 정적 검증

- 시나리오 8,427개, 전투 5,355개, 메뉴 28개가 원문 추출 레코드와 일치
- 번역 페이로드 16,288개에서 일반 일본어 잔존 0건
- BTTMES 스크립트 점프 8,750곳 검사, 메시지 중간 착지 0건
- SCEDATA 128개 멤버와 파일럿·로봇 백과 사전 재빌드
- Track 1 크기 650,607,888바이트(원본 대비 468,048바이트 증가)
- 에뮬레이터는 실행하지 않았습니다. 사용자가 별도 허가하지 않은 상태에서 정적 빌드와 바이너리 검증만 수행했습니다.
