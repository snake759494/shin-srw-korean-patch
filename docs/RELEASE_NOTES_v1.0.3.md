# v1.0.3 — 강화 확인창 및 크로노클 대사 수정

GitHub 이슈 #7과 #8의 제보를 반영한 안정 릴리스입니다. v1.0.1의 ISO 배치와
Track 2 CUE 프리갭 구조를 유지하고, 실행 파일 내부의 강화 확인창과 시나리오 대사를 교정했습니다.

## 수정 내용

- 강화 확인창 두 곳의 숫자 사이에 남아 있던 원문 `が,` 리터럴을 `에서 `로 교체했습니다.
  첫 번째 창은 `공격력 [현재값]에서 [변경값]` 형태로, 두 번째 공통 창도 같은 규칙으로
  처리됩니다.
- 모든 고정 확인 버튼의 `はい/いいえ`를 `네/아뇨`로 통일했습니다. `아뇨`는 원본
  버튼 폭을 유지하기 위해 미사용 8×16 반각 슬롯 `0xED`에 `아`를 넣고 `뇨`를 기존
  16×16 한글 슬롯으로 이어 붙였습니다.
- 두 강화창 모두 원본 terminator 뒤의 여유 바이트만 사용했습니다. 실행 파일 크기와
  EXE/SCEDATA/BTTMES 인덱스 테이블의 위치는 바뀌지 않습니다.
- 시나리오 `SCE-006-0051`의 크로노클 대사에서 문맥에 맞지 않던 `뒤진다고`를
  `죽는다고`로 수정했습니다. 다른 대사나 화자 레코드는 변경하지 않았습니다.

## 정적 검증

- 원본 Track 1/2 크기·SHA-256 및 추출 매니페스트 일치
- EXE 고정 라벨 474개 대조, 418개 적용, 초과 0개
- 강화 리터럴 2/2 적용, 새 terminator 위치 확인
- SCEDATA 128개 멤버 재압축·런타임 버퍼 검증
- BTTMES 점프 8,750곳 검사, 메시지 중간 착지 0건
- 출력 Track 1 크기 650,607,888바이트(원본 대비 468,048바이트 증가)
- 출력 Track 1 SHA-256 `57e234ba057ebb1581015762fa0b95146f7678eac51e0f9fc9635dfe018ef8c8`
- xdelta를 원본에 역적용해 릴리스 이미지 SHA-256과 일치하는지 확인
