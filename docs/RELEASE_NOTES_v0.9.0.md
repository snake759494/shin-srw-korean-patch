# v0.9.0 — 첫 공개

신 슈퍼로봇대전(SLPS-00550) 전체 한글화 첫 릴리스입니다.

## 한글화 범위

- 시나리오 대사 8,427 레코드, 전투 대사 5,355 레코드
- 메뉴·시스템 메시지 전체
- 파일럿·로봇·무기 이름, 시나리오 제목
- 정신기·지형·특수능력 설명
- 파일럿 백과 347 · 로봇 백과 242 레코드

폰트는 Galmuri14 를 12×12 글리프로 변환해 게임 폰트 테이블에 삽입했습니다.

## 이번 릴리스에서 해결한 것

플레이 검증 과정에서 잡은 엔진 쪽 문제들입니다.

- **시나리오 3 대사 밀림** — 이벤트 프로그램의 대사 디스패치 명령 중 `0x86`/`0x87` 계열
  236곳이 재배치되지 않아, 번역 후 대사가 한 칸씩 밀렸습니다.
- **상태 메뉴의 유령 항목과 전투 중 정지** — 고정폭 라벨을 종료자 *뒤에* 채워 넣는 바람에
  순차 목록에 없는 항목이 하나 생기고 이후 인덱스가 전부 밀렸습니다. 채움을 종료자 앞으로 옮겼습니다.
- **정신기 설명창에 엉뚱한 글자** — EXE 문자열 풀에서 같은 내용을 공유해 저장하면
  "종료자를 지나 다음 줄을 읽는" 창이 엉뚱한 문자열에 도달합니다. 리테일과 같은 물리 순서로
  각자 사본을 두도록 바꿨습니다. 테이블이 가리키지 않고 이어 읽기로만 도달하는 레코드 9개도 복원했습니다.
- **전투 맵 지형 패널이 통째로 비어 있던 문제** — 패널이 인자 링 버퍼에 밀어넣는
  **길이 접두사가 하드코딩된 상수 6** 이었습니다. 일본어는 두 분기 모두 정확히 6바이트라
  문제가 없었지만 한국어는 8바이트와 7바이트라, 두 번째 삽입이 남은 글리프 바이트를 길이로
  읽어 링 전체를 스크립트로 실행해 버렸습니다. 두 상수를 실제 길이로 고쳤습니다.
  (번역문은 한 글자도 줄이지 않았습니다.)
- **대사 줄 넘침 전수 정리** — 한 줄 216px 을 넘겨 잘리던 1,781 레코드를 규칙에 맞게 재배치했습니다.
  넘친 단어를 다음 줄로 내리고, 그 결과 다시 넘치면 또 다음 줄로 넘기는 연쇄 처리에,
  둘째 줄부터는 들여쓰기 한 칸을 유지합니다.
