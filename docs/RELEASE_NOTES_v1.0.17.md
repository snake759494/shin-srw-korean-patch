# 신 슈퍼로봇대전 한글패치 v1.0.17

지상편 1화부터 27화까지 진행하며 올려 주신 제보(#21~#23)를 반영한 대사 수정 릴리스입니다.
세이브 데이터는 그대로 쓰실 수 있습니다.

## 대사 수정 (#21, #22, #23)

- 신고된 화면의 대사 145줄을 원문과 대조해 고쳤습니다.
  - 원문이 질문인 대사에 물음표를 넣었습니다.
  - 요청하신 곳에 마침표를 넣었습니다.
  - 단어 중간 띄어쓰기를 고쳤습니다(「예 산이」, 「성계 에」, 「해구 로」, 「발견당했 을지도」 등).
  - 어색한 문장을 다듬었습니다(하이넬·장갈의 궁중 말투, 퀘스처럼 제안해 주신 문장 등).
- **줄 바꿈**: 대사 창은 한 페이지에 3줄을 보여 줍니다. 4줄째가 혼자 다음 페이지로 넘어가던 대사를
  3줄 이내로 다시 나눴습니다. 한 단어만 줄에 남거나 단어가 두 줄로 갈리지 않게 했습니다.
- 1화의 고정 크기 대사(「빔포? 말도 안돼!」, 「뭐야..누구지?」, 「기지에서 대공마룡대가 기다린다.」 등)도
  원래 바이트 크기 안에서 고쳤습니다.
- 동방불패 「ぶぁくはつっ!!」가 웃음소리로 잘못 옮겨져 있던 것을 「폭발!!」로 고쳤습니다.

## 표시 수정

- **5화 시나리오 제목**: 『류세이=다테』 → 『류세이 다테』
- **닥터 J (#22)**: v1.0.16에서 빠뜨린 대사 속 「닥터 J」 8곳을 「닥터J」로 고쳤습니다.
- **저장·로드 메뉴 (#22)**: 「클리어 면」 → 「클리어한 맵 저장.」, 「저장한 면」 → 「저장한 맵 로드.」
- **파일럿 교체 (#22)**: 「파일럿 교체용.」 → 「파일럿 교체.」
- **다음 맵 (#22)**: 설명을 「다음 맵으로」로 바꿨습니다. 「다음 맵 진행」은 칸(11바이트)에 들어가지 않습니다.

## 이번에 고치지 않은 것

- **볼테스 합체·가이킹 발진·동방불패 공격 장면의 일본어 (#21)**: 대사 데이터가 아니라 연출 화면에 그려진
  그래픽입니다. 디스크 전체를 검색해도 문자열로는 없습니다. 그래픽 한글화는 별도 작업으로 진행하겠습니다.
- **브라○가 (#21)**: 원작의 패러디 가림 표기입니다. ○는 글자 O가 아니라 가림 기호입니다.
- **군법회의감 / 기억해 두어라 / 뽀옹 (#22, #23)**: 다른 대사와 표기를 맞추거나 원문 뜻을 따르느라 그대로 두었습니다.
  이유는 각 이슈 댓글에 적었습니다.
