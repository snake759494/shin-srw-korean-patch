# 신 슈퍼로봇대전 한글패치 v1.0.18

지상편 30화부터 통합편 엔딩까지 진행하며 올려 주신 제보(#24~#27)를 반영한 대사 수정 릴리스입니다.
세이브 데이터는 그대로 쓰실 수 있습니다.

## 대사 수정 (#24, #25, #26, #27)

- 신고된 화면의 대사 132줄을 원문과 대조해 고쳤습니다.
  - #24(~30화): 33곳 — 오타, 띄어쓰기, 어색한 문장, 줄 바꿈
  - #25·#27(~32화, 통합편 엔딩): 52곳 — 원문이 질문인 대사에 물음표 추가, 문장 다듬기
  - #26(~35화): 47곳 — 「습래」 → 「습격」 등 용어 정리
- 같은 대사가 여러 루트(57·58·59·63·65화, 68~72화)에 사본으로 있는 경우 모두 함께 고쳤습니다.
- 대사 창 한 페이지 3줄, 전투 창 이름 1줄 + 대사 2줄, 한 줄 20칸 규칙을 모두 지켰습니다.
