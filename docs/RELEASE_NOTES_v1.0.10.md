# 신 슈퍼로봇대전 한글패치 v1.0.10

v1.0.10은 열린 제보 이슈 #108~#125를 개별 화면만 고치는 방식으로 처리하지 않고,
각 제보를 원본 일본어 레코드와 대조한 뒤 같은 원문이 복제된 모든 시나리오·전투
레코드와 공용 문자열 풀까지 다시 빌드한 버전입니다. 이전에 해결된 #74와 #107도
이번 배포물에 대해 구조 검증을 반복했습니다.

이번 버전은 사용자가 지정한 절차에 따라 에뮬레이터를 실행하지 않았습니다. 대신 원본
덤프에서 다시 추출한 데이터, 번역 ID 전체, 압축 블록, 포인터·점프 그래프, 실행 파일의
고정 문자열 테이블, xdelta 공개 패키지를 자동 검사했습니다.

### #119 — 정신 커맨드 이름 오류

원인은 번역문 자체의 한 항목이 아니라, 실행 파일의 정신 커맨드 고정 문자열 테이블이
글리프 인덱스와 어긋나 일부 일본어 슬롯을 읽는 문제였습니다. `SLPS_005.50`의
정신 커맨드 포인터 테이블과 문자열 아레나를 다시 읽고, 실제 사용되는 31개 항목을
모두 새 한글 글리프 맵으로 검사했습니다.

검사한 항목은 다음과 같습니다.

`근성`, `대근성`, `보급`, `우정`, `신뢰`, `사랑`, `격노`, `기합`, `가속`, `열혈`,
`필중`, `번뜩임`, `행운`, `각성`, `위압`, `봐주기`, `집중`, `격려`, `재동`, `부활`,
`은신`, `탈력`, `자폭`, `탐색`, `족쇄`, `교란`, `정찰`, `철벽`, `혼`, `기적`, `간파`.

각 포인터가 문자열 아레나 안을 가리키는지, `FF` 종결을 갖는지, 인코딩된 바이트가
기대한 한글과 정확히 일치하는지를 검사했습니다. 제보된 `혼→랜`, `가속→큐`,
`행운→앱`, `집중→탱`, `열혈→밟`, `번뜩임→비`, `간파→뻘`과 일본어 잔류 항목을
대표 사례가 아닌 전체 31개 테이블 검증으로 확장했습니다.
